A deadpan one-line AI out-of-office reply where the agent's own backup turns out to be on leave too, for the [Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) bounty on make.fun.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes a single line (under 160 characters, no trailing newline) to `/output/entry.txt` using only the Python 3 standard library, with no network access.
